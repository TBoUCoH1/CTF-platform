RSA Challenge - Weak Modulus
================================

Перехвачено RSA зашифрованное сообщение.
Модуль n выглядит подозрительно маленьким...

PUBLIC KEY:
n = 3233
e = 17

ENCRYPTED MESSAGE:
c = 67

ЗАДАНИЕ:
1. Факторизуйте n на простые множители p и q
2. Вычислите φ(n) = (p-1)(q-1)
3. Найдите d = e^(-1) mod φ(n)
4. Расшифруйте: m = c^d mod n
5. Флаг имеет формат: CTF{weak_rsa_p_q} где p < q

ПОДСКАЗКА:
n очень маленькое, можно факторизовать вручную или онлайн:
- factordb.com
- alpertron.com.ar/ECM.HTM
- или просто перебором до sqrt(n)

Удачи!
