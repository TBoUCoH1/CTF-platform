Вы успешно обнаружили скрытый ZIP-архив внутри этого изображения в формате PNG!

Это "полиглотский файл" - файл, который доступен в нескольких форматах:
- Пользователи, просматривающие PNG, видят его как обычное изображение
- Пользователи, извлекающие ZIP-файлы, видят его как архив

Флаг такой: CTF{polyglot_file_format}

Как это работает:
Файлы PNG имеют маркер конца, который указывает на конец графических данных.
Файлы ZIP хранят свой центральный каталог в конце файла.
Добавляя данные ZIP после маркера отправки в формате PNG, мы создаем файл
, который работает в обоих форматах!
