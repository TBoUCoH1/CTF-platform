# Платформа CTF версии 1.0.0

Capture The Flag Training Platform - настольное приложение для Linux

### Системные требования

- **Операционная система**: Ubuntu 20.04+, Debian 11+ или совместимая с ней
  
- **Оперативная память**: минимум 2 ГБ
  
- **На диске**: 1 ГБ свободного места
  
- **Docker**: Требуется (будет установлен автоматически)
  

# Установка

### Быстрая установка:

./install.sh

### Инструкции по установке:

1. Извлеките архив
  
2. Запустите: `./install.sh`
  
3. Запустите из меню приложений
  

# Использование

### Запустите приложение:

- **Из меню**: Найдите "CTF-platform"
  
- **Из терминала**: `ctf-platform`
  

## Ручное управление:

**Запустить серверную часть:**

./start-backend.sh

**Остановить серверную часть:**
./stop-backend.sh

**Только интерфейс:**
./CTFApp

# Устранение неполадок

### В разрешении отказано:

sudo usermod -aG docker $USER
Затем выйдите из системы и снова войдите в систему

### Порт уже используется:

sudo netstat -tulpn | grep -E '5000/8080/5432'

## Функции

- 21 задача CTF (веб, крипто, криминалист и т. д.)
  
- Список лидеров
  
- Отслеживание прогресса
  
- Подсказки
  
- Тёмная тема
  

## Порты по умолчанию

- Frontend: Qt Desktop App
- Backend API: http://localhost:8080
- Web Interface: http://localhost:5000
- Database: localhost:5432
